# Code of Conduct

We want Grain Studio to be a useful and welcoming open-source project.

Be respectful, critique ideas rather than people, document technical claims, and assume good intent while protecting contributor boundaries. Harassment, discrimination, doxxing, or abusive conduct is not accepted in project spaces.

Report conduct concerns privately to the project maintainers. Maintainers may edit, remove, or reject contributions and participation that violate these expectations.
