# Security policy

## Supported versions

Security fixes are applied to the latest release on the default branch.

## Reporting

Please report a suspected vulnerability privately to the repository owner instead of opening a public issue. Include reproduction steps, affected browsers, and the expected impact. Do not attach real private images.

## Privacy boundary

Grain Studio processes images in the browser. The default build contains no upload API, analytics SDK, authentication, or remote image-processing endpoint. A deployment that adds any network transfer must disclose it in the interface and documentation.
